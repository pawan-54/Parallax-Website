# Parallax Website

A simple parallax scrolling website built with **HTML5** and **CSS3**. It uses large background images and fixed background attachment to create a layered scrolling effect.

## Preview

Open `index.html` in a web browser to view the website.

## Features

- Parallax-style background sections
- Multiple nature image sections
- Centered text overlays on background images
- Light and dark content sections
- Separate HTML and CSS files

## Technologies Used

- HTML5
- CSS3

## Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/Parallax-Website.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

No package installation or build step is required.

## Notes

- The parallax effect is created with the CSS property `background-attachment: fixed`.
- Fixed background behavior can vary on mobile browsers. Test on mobile devices before describing the project as fully responsive.
- Replace the sample section text with your own content if you want to make the project more complete.
